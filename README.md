# 🧮 BMI Calculator

### Calculate your Body Mass Index with a simple, clean, and responsive web application.

A beginner-friendly web development project built using **HTML5, CSS3, and JavaScript**. Enter your height and weight to calculate your BMI, view your BMI category, and receive immediate feedback with input validation.

---

## ✨ Features

- 🧮 **Instant BMI Calculation** — Calculates BMI using height and weight.
- 📊 **BMI Category** — Displays Underweight, Healthy Weight, Overweight, or Obesity.
- ✅ **Input Validation** — Handles empty, zero, negative, and invalid inputs.
- ⚡ **Instant Results** — Displays the calculated BMI up to two decimal places.
- 🔄 **Dynamic Feedback** — Updates results and error messages based on user input.
- 📱 **Responsive Design** — Designed to work across different screen sizes.
- 🎨 **Clean Interface** — Simple and user-friendly layout.

## 🧠 How BMI Is Calculated

Body Mass Index (BMI) is calculated using the following formula:

**BMI = Weight (kg) ÷ Height (m)²**

Height entered in centimeters is converted into meters before the calculation.

### Example Calculation

| Input | Value |
|---|---:|
| Height | 170 cm |
| Weight | 65 kg |
| Calculated BMI | 22.49 |
| Result | Healthy Weight |

## 📊 BMI Categories for Adults

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 to below 25 | Healthy Weight |
| 25 to below 30 | Overweight |
| 30 and above | Obesity |

**Note:** These ranges are general screening guidelines for adults and are not a substitute for professional medical advice or diagnosis.

## 🚀 Getting Started

Run this project locally in a few simple steps.

### Prerequisites

- A modern web browser
- A code editor such as Visual Studio Code (optional)

### Installation

1. Clone this repository:

   `git clone https://github.com/Rohit6404/bmi-calculator.git`

2. Open the project folder in your code editor.
3. Open `index.html` in your browser.
4. Enter your height in centimeters and weight in kilograms.
5. Click the calculate button to view your BMI result.

No additional packages or dependencies are required.
